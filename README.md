# devops-git-project

A small project to practice Git and GitHub version-control workflows as part of the DevOps internship (Task 4).

## What this repo demonstrates
- Repository initialised and pushed to GitHub
- `main`, `dev` and feature branches
- Pull requests to merge changes
- `.gitignore` for excluding unwanted files
- Git tags for releases

## Branching strategy
- `main`: stable, release-ready code
- `dev`: integration branch for new work
- `feature/*`: one branch per change, merged into `dev` via pull request
